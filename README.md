# 🤖 HR-Assistance-AI: The Future of Intelligent Recruitment

[![Aryan Thakur](https://img.shields.io/badge/Author-Aryan%20Thakur-blue?style=for-the-badge)](https://github.com/aryxn1233)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

An advanced, AI-driven hiring platform that streamlines the recruitment process through intelligent automation. Featuring **real-time AI video interviews**, **automated talent assessment**, and a **data-rich recruiter dashboard**, this platform bridges the gap between candidates and companies with cutting-edge technology.

---

## 🌟 Key Features

### 1. 🎙️ AI Video Interviews (Powered by D-ID & Gemini)
- **Interactive Avatars**: Dynamic, lifelike AI interviewers that engage candidates through speech and facial expressions.
- **Adaptive Questioning**: Real-time evaluation of candidate responses to adjust question difficulty on the fly.
- **Natural Language Understanding**: Advanced speech-to-text and text-to-speech integration for seamless conversation.

### 2. 📊 Intelligent Recruiter Dashboard
- **Real-Time Monitoring**: Watch live interviews and see candidate responses/evaluations as they happen.
- **Automated Scoring**: Instant analysis of technical skills, communication, and confidence.
- **Comprehensive Reports**: Detailed feedback and hiring recommendations generated by Gemini AI.

### 3. 📄 Automated Talent Sourcing
- **Resume Parsing**: Seamless extraction of skills and experience from PDF uploads.
- **Smart Ranking**: Applications are automatically scored and ranked based on job requirements.
- **Job Management**: Complete workflow for creating, managing, and tracking job postings.

## 🛠️ Technology Stack

### Frontend
- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **UI & UX**: [Tailwind CSS](https://tailwindcss.com/), [Framer Motion](https://www.framer.com/motion/), [Radix UI](https://www.radix-ui.com/)
- **State Management**: [Zustand](https://zustand-demo.pmnd.rs/)
- **Authentication**: [Clerk](https://clerk.com/)
- **Visualization**: [Three.js](https://threejs.org/), [Recharts](https://recharts.org/)

### Backend
- **Framework**: [NestJS](https://nestjs.com/)
- **Database**: [PostgreSQL](https://www.postgresql.org/) with [TypeORM](https://typeorm.io/)
- **AI Engine**: [Google Gemini Pro](https://deepmind.google/technologies/gemini/) & [OpenAI](https://openai.com/)
- **Video Interaction**: [D-ID Client SDK](https://www.d-id.com/)
- **Real-time Communication**: [Socket.io](https://socket.io/)

## 🔄 Core Workflows

### 🎖️ Recruiter Workflow
1. **Create Job**: Post a job description defining required skills and experience.
2. **Review Candidates**: View parsed resumes and AI-assigned scores.
3. **Invite to Interview**: One-click invite for selected candidates.
4. **Monitor Live**: (Optional) Join the live session to observe candidate performance.
5. **Final Decision**: Review the AI-generated report and make hiring decisions.

### 🎓 Candidate Workflow
1. **Apply**: Upload resume and fill in basic details.
2. **Accept Invite**: Choose a session from the "Upcoming Interviews" section.
3. **Take Interview**: Interact with the AI Avatar, answering questions in real-time.
4. **View Result**: Get immediate confirmation of interview completion.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- PostgreSQL
- API Keys: Clerk, Gemini, D-ID, OpenAI

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/aryxn1233/HR-Assistance-AI-.git
   cd HR-Assistance-AI-
   ```

2. **Install Dependencies**
   ```bash
   npm install
   cd backend && npm install
   cd ../ai-hiring-platform && npm install
   ```

3. **Configure Environment**
   - Create `.env` files in both `backend` and `ai-hiring-platform` using the provided templates.

4. **Run the Project**
   ```bash
   # From the root directory
   npm run start
   ```
